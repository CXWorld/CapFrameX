# CapFrameX 1.9.0 screenshots

Captured from the application at version 1.9.0.7 with the release channel. The initial portable screenshot build was produced from commit `4456e732130479b9fc874c578e6a752149e7dd70`.

- `comparison.png` and `report.png` show the Cyberpunk 2077 comparison and report prepared by the maintainer for this release.
- `overlay-options.png` was refreshed from the revised 1.9.0.8 build. It shows the disabled in-game option, its certificate notice, and the hook-free selection after migration.
- The remaining screenshots use a separate portable configuration and the public capture fixtures in `source/CapFrameX.Test/TestRecordFiles`.
- `info.png` shows the live hardware dashboard of the screenshot system.

These are direct window captures of the application. The header banner in `images/CX_Header_Logo_Wide.jpg` uses the current branding from `source/CapFrameX/Icons/X_Banner.jpg`.
